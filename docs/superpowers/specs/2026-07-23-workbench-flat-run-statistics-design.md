# 工作台扁平运行统计与移动端防重叠设计

**日期：** 2026-07-23  
**范围：** 桌面端工作台与局域网移动端工作台

## 目标

- 保留现有 6 项本次运行统计，不扩展后端接口。
- 将大尺寸统计卡片改为紧凑的扁平统计项。
- 桌面端与局域网移动端使用同一组件和视觉语言。
- 消除部分矮屏手机上“最近事件”与“本次运行统计”重叠的问题。

## 根因

`OverviewView` 的 `.view-stack` 目前固定为 `auto auto 1fr` 三行，但页面实际依次放置页头、就绪状态、最近事件区域和运行统计四个主要区块。运行统计进入隐式第四行后，第三行仍被限制为剩余高度；在部分矮屏设备上，最近事件的固定高度内容会从被压缩的第三行溢出，并覆盖第四行的统计标题。

## 布局设计

工作台总览改为明确的四段自然布局：页头、就绪状态、最近事件区域、运行统计。页面整体继续由现有 `.main-content` 承担纵向滚动，最近事件列表保留自己的有限高度和纵向滚动能力。四个区块不使用相互覆盖或绝对定位。

运行统计采用响应式网格：

- 桌面端：3 列 2 行。
- 局域网移动端：2 列 3 行。
- 每个统计项保持稳定的单行高度，列宽使用 `minmax(0, 1fr)`，避免长数值撑破容器。

## 统计项视觉

每项由“彩色 Lucide 图标、指标名称、右对齐数值”组成。项目使用浅灰白背景、无边框、无阴影、小圆角和紧凑内边距，不复用现有大尺寸 `.metric-card`。

六项及图标语义如下：

| 指标 | 图标语义 | 颜色方向 |
| --- | --- | --- |
| 收获次数 | 收获/植株 | 绿色 |
| 务农次数 | 农具/作业 | 青绿色 |
| 偷菜次数 | 隐蔽/获取 | 橙色 |
| 帮助次数 | 协助/爱心 | 蓝色 |
| 捣乱次数 | 警示/破坏 | 红色 |
| 出售预估收益 | 金币/收益 | 金黄色 |

图标只作视觉区分，指标名称和数值仍是完整可访问文本。出售预估收益继续使用现有紧凑格式和完整数值 `title`，未准备完成时显示 `-`。

## 组件与数据流

`OverviewView` 的 `WorkspaceRunStatistics` 输入契约保持不变。组件继续在本地完成时长更新、数值格式化和收益格式化，只把 `WorkbenchMetric` 从通用卡片结构改成专用扁平统计项，并为每项传入图标和色调。

不新增请求、不修改 Go 服务、不改变轮询频率，也不改变统计值的含义。桌面端和远程端共享同一份 JSX，仅通过现有 `.app-shell-remote` 移动断点调整列数和间距。

## 异常与边界状态

- 缺失或非数值计数继续显示 `0`。
- 未就绪的出售预估收益显示 `-`。
- 超长数值不得覆盖相邻指标；必要时省略显示，完整收益保留在 `title` 中。
- 320px 级窄屏仍保持两列，名称和数值不得互相覆盖。
- 矮屏设备通过页面滚动访问全部内容，最近事件与统计区之间保持正常文档流间距。

## 测试与验收

1. 组件测试确认仍渲染现有 6 项及对应图标，不出现旧 `.metric-card` 结构。
2. 样式测试确认桌面端为 3 列、局域网移动端为 2 列，并确认统计项无边框、无阴影且数值右对齐。
3. 回归测试确认工作台使用四段自然布局，最近事件容器的内容不会溢出覆盖统计区。
4. 运行相关 Vitest 测试和完整前端测试。
5. 运行前端构建并确认 `public/app/index.html` 引用新生成资源。
6. 使用桌面与窄屏移动视口进行浏览器截图检查，重点检查 320-390px 宽、较矮视口下的重叠、文字截断和底部导航遮挡。

## 非目标

- 不增加参考图中的种植、施肥、清黄虫或狗礼包等新统计字段。
- 不调整运行统计后端计算逻辑。
- 不重做工作台页头、就绪状态或底部导航视觉。
