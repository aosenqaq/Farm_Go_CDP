# Smart Plant Fertilizer Design

## Goal

在“种植施肥策略”中新增“智能无机肥”和“智能有机肥”。智能策略根据本地 `resources/gameConfig/Plant.json` 的作物阶段配置，在作物进入“大叶子”阶段时施加对应肥料；不具备“大叶子”阶段的作物保持原有种植后施肥行为。

## Strategy Values

前端和持久化配置使用两个新值：

- `smart_normal`：智能无机肥
- `smart_organic`：智能有机肥

现有 `none`、`normal`、`organic` 的语义和行为不变。

## Crop Classification

后端从 `Plant.json` 加载作物信息，按运行时提供的 `plantId` 优先、`seedId` 次之识别作物。对每个作物的 `grow_phases`：

1. 解析以分号分隔的 `阶段名称:秒数` 条目。
2. 忽略时长为零或无效的条目。
3. 计算所有正时长中的最大值。
4. 仅当存在名称精确为“大叶子”的阶段，且该阶段时长等于最大值时，作物属于智能施肥目标。

“大叶子”与其他阶段并列最长时仍然属于智能施肥目标。没有“大叶子”、或“大叶子”不是最长阶段的作物属于回退作物。未能从本地配置识别的作物不施肥，以避免在配置缺失或运行时数据异常时错误消耗肥料。

## Runtime Behavior

### 种植后

- `normal` 和 `organic` 继续在种植成功后立刻批量施肥。
- `smart_normal` 和 `smart_organic`：
  - 智能施肥目标不在种植后立即施肥。
  - 回退作物立即使用对应的 `normal` 或 `organic` 肥料。

### 自动施肥巡查

每轮已有的自动施肥任务读取自家农场状态。智能策略开启后，即使“催熟策略”为“不催熟”，该任务也会执行智能巡查：

- 仅选择自家农场中已识别的智能施肥目标。
- 仅当运行时当前阶段名称为“大叶子”时，使用智能策略对应的肥料类型施肥。
- 已有催熟策略仍照常工作；同一轮中智能目标优先，并从催熟目标中排除，防止重复施肥。
- 没有智能目标且催熟策略关闭时，任务正常跳过。

### 多季补肥

多季补肥启用时：

- `normal` 和 `organic` 继续在后续季开始后立即补肥。
- 智能策略下，智能施肥目标等待后续自动施肥巡查到“大叶子”阶段再施肥。
- 回退作物仍在后续季开始后立即按对应肥料类型补肥。

## Scope and Error Handling

- 不更改游戏运行时的批量施肥协议，继续调用 `gameCtl.fertilizeLandsBatch`。
- 不修改催熟策略的选项或阈值语义。
- 本地 `Plant.json` 加载失败或作物 ID 无法映射时，智能路径跳过该地块并保留任务的其他有效目标。
- 多格作物以运行时提供的占位锚点地块为唯一施肥目标。

## Testing

- Frontend：新增两项下拉选项并保留既有选项。
- Go 配置/分类：验证最长“大叶子”、并列最长、没有“大叶子”、较短“大叶子”、无效配置和未知作物。
- Go 自动化：验证智能种植后只立即施肥回退作物，智能巡查在催熟关闭时仍对“大叶子”施肥，多季补肥的智能/回退分支，以及智能与催熟同轮去重。
- 回归：原有普通/有机种植后施肥、多季补肥和催熟测试保持通过。
