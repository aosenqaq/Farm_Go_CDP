# Lan WebUI 运行模式移动端抽屉设计

## 目标

优化 Lan WebUI 的农场自动化“运行模式”界面在手机窄屏下的显示。模式选择页和二次确认页统一使用内容自适应的底部抽屉，消除固定高度造成的空白区域，并让主操作保持在拇指可及区域。

## 范围

- 仅修改远程 Lan WebUI 的窄屏样式（`max-width: 760px`）。
- 覆盖“运行模式”选择抽屉和“确认运行模式”二次确认抽屉。
- 保留现有桌面端居中对话框、运行模式业务逻辑、文案、可访问性标签、保存状态和错误处理。

不改变自动化运行模式的保存接口、切换行为或其他弹窗的样式。

## 交互与布局

远程界面在窄屏下继续由 `.automation-dialog-backdrop` 将运行模式容器贴齐屏幕底部。运行模式容器不再使用固定的 `70dvh` 高度；其高度由选择卡片、守护说明和底部操作栏决定，并以可视窗口高度作为上限。内容超出上限时，只有中间正文区域滚动，头部和底部操作栏保持可见。

抽屉具有顶部圆角和短横条提示，保持与移动端抽屉的视觉语言一致。抽屉头部为标题和关闭按钮；选择页的两张模式卡片在窄屏下单列紧凑展示，当前模式、选择状态、说明和错误文案沿用现有状态。守护服务说明紧随卡片显示，不因容器的剩余高度被推到远处。

底部操作区使用两个等宽按钮：取消/返回与下一步/确认切换。其保留安全区底部内边距；保存期间现有的禁用规则仍同时禁用关闭、返回和确认操作。

## 技术设计

修改 `frontend/src/style.css` 的移动端 `.app-shell-remote` 规则：

- `.automation-run-mode-dialog` 使用内容高度和 `max-height`，不设置固定 `height`。
- `.automation-run-mode-body` 保持为可滚动区域，确保受限高度下仍能读取全部内容。
- 通过伪元素添加仅移动端显示的抽屉提示条，并为头部增加对应的顶部留白。
- 调整移动端选择卡片的最小高度与内边距，使两种模式、守护说明和操作栏构成紧凑的阅读顺序。
- 将运行模式抽屉底栏设为等宽双列布局，并保留已有按钮状态与颜色体系。

`frontend/src/views/AutomationView.tsx` 不改变状态、事件处理或接口；现有选择、二次确认、保存成功和失败反馈保持不变。

## 测试与验证

- 在 `AutomationView.test.tsx` 增加样式契约断言：移动端运行模式抽屉不得保留固定 `70dvh` 高度，正文可滚动，底栏为双列等宽布局，并包含移动端抽屉提示条样式。
- 运行现有的运行模式交互测试，验证当前模式不可重复确认、二次确认、成功刷新和失败保留弹窗。
- 运行前端完整测试与生产构建。
- 在移动端宽度下检查选择页和二次确认页，确认抽屉贴底、无多余空白、正文可滚动、按钮无重叠且可见。
