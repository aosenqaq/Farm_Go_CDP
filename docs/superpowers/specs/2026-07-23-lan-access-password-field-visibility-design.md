# LAN 设置密码输入框可见性修复设计

日期：2026-07-23

## 目标

让“局域网 Web 控制台”中的新访问密码与确认访问密码输入框始终清晰可见、可交互，并将保存按钮默认文案统一为“保存设置”。

## 原因

`LANAccessSettingsPanel` 的密码输入框使用 `type="password"`，而现有通用设置表单样式只覆盖了下拉框和数字输入框。密码框因而回退到浏览器默认外观，在当前浅色主题中缺少可见边界和稳定高度。

## 方案

- 仅在 `.lan-access-form` 范围内，为 `input[type="password"]` 设置与端口输入框一致的宽度、38px 高度、边框、圆角、背景色、文字颜色和内边距。
- 保持现有密码状态、长度校验、确认校验和保存 API 参数不变。
- 将保存按钮在非保存状态下的文本从“保存 LAN 设置”改为“保存设置”。
- 扩展组件测试，锁定两个密码输入框和更新后的按钮文案。

## 非目标

- 不修改其他设置面板或全局输入框规则。
- 不改变 LAN 服务配置、密码策略或保存行为。

## 验证

- 新增断言确认两个密码字段以 `type="password"` 渲染，且保存按钮显示“保存设置”。
- 运行 LAN 设置组件测试和前端生产构建，确认测试、类型检查与 CSS 打包通过。
