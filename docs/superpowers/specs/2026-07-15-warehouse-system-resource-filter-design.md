# 仓库系统资源隐藏设计

## 目标

仓库页面不显示以下八种系统资源：普通化肥容器、有机化肥容器、种植经验、普通收藏点、典藏收藏点、金币、点券、金豆。

## 范围

仅过滤仓库前端列表的显示数据。后端仓库快照、出售接口、自动出售设置和原始分类摘要不改变。

## 方案

在 `WarehousePanel` 的前端渲染数据处理处维护一个按物品名称匹配的只读集合。仓库条目进入分类合并、分类筛选、勾选和表格渲染前，先排除集合中的名称。

名称过滤适合当前已有的截图证据，且仅影响用户可见的仓库列表；不依赖尚未确认的运行时物品 ID，也不会改变后端业务逻辑。

## 行为

- 八种指定系统资源不会出现在“全部”或任意仓库分类中。
- 其余仓库物品维持原有分类、选择和出售行为。
- 过滤后的系统资源不会被“全选可出售”纳入待出售物品。
- 后端返回的原始仓库数据保持不变，刷新后继续在前端应用过滤。

## 验证

在 `AssetsLandView` 的前端测试中构造同时包含指定资源和普通可出售物品的仓库快照，断言：

- 八种资源名称均不出现在渲染 HTML 中。
- 普通物品仍显示。
- 既有仓库渲染和出售相关测试继续通过。
