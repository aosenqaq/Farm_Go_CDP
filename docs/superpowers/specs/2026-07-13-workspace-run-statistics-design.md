# 工作台本次运行统计

## 目标

在工作台底部空白区域增加“本次运行统计”，帮助用户查看当前应用启动后的自动化成果。

## 界面

采用用户确认的 A 方案：一个与账户状态页一致的紧凑统计区。标题为“本次运行统计”，右侧显示持续运行时间；下方以六张指标卡显示收获次数、务农次数、偷菜次数、帮助次数、捣乱次数和本次运行出售预估收益。窄窗口允许指标卡自然换行。

## 数据边界

运行会话从应用进程启动时开始，到应用退出或重启时清零。统计只覆盖当前会话内自动化成功产生的操作；不复用账户状态页按自然日保存的历史数据。

出售预估收益取当前账号仓库快照中可出售物品的估值。仓库未加载或不可用时显示空值，而不显示历史数据或推测值。

## 实现与验证

后端提供当前会话汇总 DTO，并在现有自动化动作成功路径累加对应指标。工作台轮询或刷新时读取该 DTO 并更新统计区。新增后端会话统计测试与工作台渲染测试，运行受影响的前端测试、后端测试和前端构建。
