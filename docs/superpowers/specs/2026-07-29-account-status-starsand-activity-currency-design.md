# 账户状态页星砂活动货币设计

## 目标

将账户状态页的本期活动货币从“荷露”更新为“星砂”，并显示用户提供的星砂图标。

## 范围

`AccountStatusView` 保持现有活动货币卡片的布局、加载逻辑、不可用状态和数量格式。仓库快照处于 `runtime` 状态时，活动货币解析器只查找名称精确为“星砂”的物品；该物品有非负有限数量时显示其数量和现有分类标签。没有星砂、仓库不可用或数量无效时，继续显示“暂未获取”。

可用状态下的名称、图片替代文本和图片地址统一改为“星砂”。将用户提供的 PNG 复制为 `frontend/public/items/starsand.png`，由现有的 Vite 静态资源路径 `/items/starsand.png` 提供。

## 非目标

- 不改变活动货币卡片的视觉布局、刷新时机或数量格式。
- 不新增可配置的活动货币机制，也不修改后端仓库接口或游戏配置映射。
- 不修改无关页面、资产或测试。

## 测试

更新账户状态视图的既有可用状态夹具和断言，使其提供并断言“星砂”、`/items/starsand.png` 与 `alt="星砂"`。保留无货币时显示“暂未获取”的测试，以覆盖星砂缺失的分支。执行该测试文件和前端生产构建，确认类型检查、静态资源引用与现有页面渲染均通过。
