# 图鉴一键购买未解锁种子

## 目标

将作物图鉴现有的“解锁购买预览”和“确认购买”两个工具栏按钮合并为“一键购买未解锁种子”。用户点击后先扫描当前运行时图鉴和商店数据，再在确认弹窗内查看实际将购买的种子与数量，最后明确确认才执行购买。

## 交互设计

- 仅作物图鉴显示“一键购买未解锁种子”；超变图鉴不显示购买入口。
- 点击按钮时复用现有购买预览调用，并以“扫描中...”锁定重复触发。
- 预览成功且存在可购项时，弹出确认对话框。对话框显示可购买种类数、总数量，以及每种种子的名称和购买数量。
- 确认对话框不显示跳过条目；用户看到的每一项都是将被购买的种子。
- 没有可购项时，不打开对话框，在图鉴区域显示“没有可购买的未解锁作物种子”。
- 用户可取消弹窗。确认购买期间，操作按钮进入提交状态以避免重复购买。
- 购买成功后关闭弹窗、保留购买结果供页面状态使用并刷新图鉴；失败时弹窗保持打开并显示错误，用户可取消或重试。

## 架构与数据流

前端继续通过 `FarmAtlasBuyLockedPreview` 读取作物图鉴条目并生成购买计划。返回的 `plan.purchases` 是弹窗的唯一清单来源。用户确认后继续调用 `FarmAtlasBuyLockedCrops`，保留后端对当前运行时用户等级、商店在售状态和批量购买协议的重新校验。

购买确认弹窗作为 `AssetsLandView` 内的受控组件实现，沿用项目已有的 `dialog-backdrop`、紧凑操作按钮和颜色系统，不引入新的依赖。现有页面内联“购买预览”条带和两个旧按钮将移除。

## 错误处理

- 扫描失败：图鉴区域显示现有错误样式，不打开弹窗。
- 空计划：图鉴区域显示空计划说明，不打开弹窗。
- 提交失败：弹窗保持打开并显示错误，保证计划清单仍可核对。
- 静态预览或运行时购买不可用：按钮维持禁用状态。

## 测试与验证

- React 测试验证旧按钮和页面内联购买预览不再渲染，新的单一入口会渲染。
- React 交互测试验证扫描成功后显示计划清单，取消不会购买，确认会调用购买回调；空计划与失败状态有明确反馈。
