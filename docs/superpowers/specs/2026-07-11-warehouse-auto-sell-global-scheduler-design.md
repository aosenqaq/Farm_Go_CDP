# 仓库自动出售全局调度设计

## 目标

将当前仅在仓库页面挂载期间运行的自动出售改为调度中心管理的后台全局任务，并将出售间隔从小时调整为分钟。

## 当前问题

- 自动出售由 `AssetsLandView` 内的 `window.setInterval` 驱动。
- 离开资产/土地页面或重启应用会销毁计时器并重置计时。
- 调度中心无法查看自动出售的启停、上次执行、下次执行或失败状态。
- 配置字段和持久化键以小时为单位，新账号默认 6 小时。

现有刷新和出售调用链是真实可用的：自动出售先调用仓库刷新，从返回快照中过滤可出售且未锁定的指定分类物品，再调用 `gameCtl.sellWarehouseItems`，并保存出售记录。

## 配置与迁移

仓库自动出售设置继续作为按账号隔离的唯一配置源：

- `enabled`：是否启用自动出售。
- `intervalMinute`：自动出售间隔，最小值为 1 分钟，新账号默认 60 分钟。
- `categories`：允许自动出售的仓库分类。
- `refreshOnlyOnAutoSell`：继续固定为 `true`。

新持久化键为 `warehouse.autoSellIntervalMinute`。读取时优先使用新键；若新键不存在但旧键 `warehouse.autoSellIntervalHour` 存在，则将旧值乘以 60，写入新键并删除或停止使用旧键。这样已有用户的实际等待时长保持不变，例如 6 小时迁移为 360 分钟。无配置或无效配置归一化为 60 分钟。

运行时兼容 DTO 同步改为分钟命名，避免字段名与实际语义不一致。前端 Wails 绑定在后端结构变更后重新生成。

## 调度任务

在现有自动化任务目录中注册 `auto_warehouse_sell`：

- 显示名称：`仓库自动出售`。
- 默认关闭。
- 默认间隔：3600 秒，对应 60 分钟。
- 启用配置映射到仓库设置的 `enabled`。
- 调度间隔映射到 `intervalMinute * 60`。
- 使用协议资源，避免与其他占用同类运行时协议资源的任务发生不受控冲突。

任务新启用或间隔从关闭状态恢复时立即到期，因此启用后会立即执行一次。成功后按配置间隔安排下一次执行；失败继续使用现有调度器的退避规则。

## 后台执行流程

调度器执行 `auto_warehouse_sell` 时：

1. 使用调度器捕获的账号键读取该账号的仓库自动出售设置。
2. 若设置已关闭或没有有效分类，返回跳过结果，不执行出售。
3. 调用 `gameCtl.refreshWarehouseSnapshot` 获取最新仓库快照。
4. 仅选择分类匹配、`canSell` 为真且未锁定的物品。
5. 若没有符合条件的物品，返回成功并说明没有可出售物品。
6. 调用 `gameCtl.sellWarehouseItems`，模式标记为 `auto`。
7. 使用捕获的账号键保存出售记录，避免账号切换期间写入错误账号。
8. 将成功、失败和摘要交给现有调度状态及事件日志机制。

手动点击调度中心的运行按钮复用同一执行流程，但触发来源记为手动。

## 配置同步

仓库设置弹窗和调度中心必须操作同一份设置：

- 仓库弹窗保存后，持久化仓库设置并立即重新配置当前账号调度器。
- 调度中心保存时，提取 `auto_warehouse_sell` 的启停和秒间隔，将秒间隔规范化为整分钟后保存到仓库设置；其余任务仍保存到自动农场设置。
- 加载自动化状态时，将仓库设置映射到调度任务，确保调度中心始终显示实际持久化值。
- 账号切换继续沿用现有调度器账号隔离机制：停止旧账号调度器，加载并配置新账号任务。

若跨存储保存过程中仓库设置保存失败，保存操作返回错误且不应用新的调度配置，避免界面显示与实际持久化状态分叉。

## 前端调整

- 删除 `AssetsLandView` 中自动出售的 `setInterval`，避免与后台调度器重复执行。
- 仓库设置字段和界面文案改为分钟，默认显示 60。
- 调度中心任务表自动显示后端返回的 `仓库自动出售` 任务，包括启停、优先级、间隔、上次执行、预计下次和执行结果。
- 调度中心仍以秒保存通用任务间隔，但自动出售输入值必须按整分钟规范化并同步到仓库设置。

## 测试

- 存储测试：新账号默认 60 分钟；旧小时键按实际时长迁移；新键优先；无效值归一化。
- 目录与调度测试：任务可见、默认关闭、默认 3600 秒、启用后立即到期、后续按间隔调度。
- 执行测试：刷新、分类过滤、锁定过滤、无物品跳过、真实出售参数、自动出售记录和账号隔离。
- API 测试：仓库弹窗保存会重配调度器；调度中心保存会同步仓库设置。
- 前端测试：分钟文案和默认值正确；页面内不再存在自动出售计时器；调度中心显示任务状态。
- 回归验证：运行 Go 全量测试、前端测试和前端生产构建。

## 非目标

- 不改变仓库物品分类规则。
- 不增加按具体物品或数量阈值出售。
- 不支持多个账号同时并行运行调度器；继续只调度当前确认账号。
- 不改变调度中心其他任务的时间单位或调度语义。
