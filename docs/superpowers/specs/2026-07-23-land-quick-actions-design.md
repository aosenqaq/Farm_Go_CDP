# 土地详情快捷操作设计

## 目标

将土地详情现有的“一键催熟”“一键无机肥”“一键有机肥”，以及新增的“一键务农”“一键铲除”“一键种植”“一键收获”，统一收纳到一个“快捷操作”入口中。

桌面端采用好友列表相同的锚定命令菜单；LAN 手机端采用相同命令集合的底部抽屉。用户已确认该响应式菜单方案。

## 范围

仅修改土地详情前端及其测试：`frontend/src/views/AssetsLandView.tsx`、`frontend/src/views/AssetsLandView.test.tsx`、`frontend/src/style.css`。

现有 Wails 绑定已经暴露 `RunFarmAutomationTask`、`FarmShovelLands` 和 `FarmLandRush`，本次不新增后端接口、协议调用、自动化配置或数据结构。

## 界面与响应式行为

土地详情操作区域不再直接并列展示三枚肥料/催熟按钮，改为单一的文字加 `ChevronDown` 的“快捷操作”触发器。

桌面端点击触发器后，在其下方打开带标题的锚定菜单。菜单顺序固定：

1. 一键务农
2. 一键收获
3. 一键种植
4. 一键铲除
5. 分隔线
6. 一键催熟
7. 一键无机肥
8. 一键有机肥

“一键铲除”使用警示色和 `Shovel` 图标；其余项目使用与实际动作匹配的 Lucide 图标。菜单可通过点击外部区域、`Escape`、关闭按钮或选择一个命令关闭。触发器带 `aria-haspopup="menu"`、`aria-expanded` 与菜单 ID，菜单使用 `role="menu"`，命令使用 `role="menuitem"`。

在 `.app-shell-remote` 且视口不超过 `760px` 时，不使用锚定浮层。触发器保持可见文字且至少有 42px 触控高度，点击后显示底部抽屉。抽屉复用好友列表命令菜单的视觉与交互契约：遮罩、固定标题、关闭按钮、独立滚动正文和每项至少 42px 的触控高度。`360px` 到 `760px` 不出现横向溢出；桌面布局不受移动规则影响。

## 动作映射

| 菜单命令 | 调用 | 既有语义 |
| --- | --- | --- |
| 一键务农 | `RunFarmAutomationTask('own_base')` | 浇水、除草、杀虫及金虫清理 |
| 一键收获 | `RunFarmAutomationTask('own_collect')` | 收获成熟作物，并沿用既有枯萎地清理 |
| 一键种植 | `RunFarmAutomationTask('own_plant')` | 按自动农场中已保存的种植策略种植空地 |
| 一键铲除 | `FarmShovelLands({ landIds })` | 批量铲除当前有作物的地块 |
| 一键催熟 | 现有 `FarmLandRush` 路径 | 保持既有催熟筛选与弹层 |
| 一键无机肥 | 现有 `FarmLandRush` 路径 | 对生长中地块施用无机肥 |
| 一键有机肥 | 现有 `FarmLandRush` 路径 | 对生长中地块施用有机肥 |

“一键铲除”从当前土地数据中选择有作物的地块，跳过空地、锁定地和无效地块。多格作物按 `occupancyAnchorLandId` 聚合并去重，确保同一株作物仅提交一次。点击命令先关闭菜单并打开确认层，确认层明确显示将铲除的地块数量和“不会收获或恢复作物”的后果；只有确认按钮才会发出 `FarmShovelLands` 调用。

## 状态与错误处理

命令可用性由当前土地运行时状态和现有动作 gate 推导：运行时未就绪、非自家农场、没有目标地块或另一个土地命令正在执行时，对应菜单项禁用并显示文字原因。

菜单、催熟弹层、肥料操作、单块土地操作和快捷命令共享一个互斥的土地操作状态，避免彼此并发提交。执行中显示对应的进行中文案，关闭菜单或确认层不会取消已提交请求。执行完成后刷新土地状态，并展示运行时成功或失败信息；失败同时保留既有土地错误呈现。

## 实现边界

在 `AssetsLandView.tsx` 内新增职责明确的局部组件/辅助函数：快捷命令触发与菜单、铲除确认层、批量铲除目标 ID 计算。组件只接受土地数据、可用性、打开状态和回调；Wails 调用及刷新仍由 `AssetsLandView` 管理。

样式增加在既有土地详情和 `.app-shell-remote` 移动段附近，参考 `.social-command-*` 的布局和交互，不修改好友社交组件或其样式合同。

## 测试与验收

前端测试覆盖：

1. 七项命令只出现在快捷操作菜单中，顺序和动作映射正确。
2. 务农、收获、种植调用既有任务 ID；催熟和两种肥料保持既有调用路径。
3. 铲除在确认前不调用后端，确认后只提交去重后的有作物锚点 ID。
4. 运行时未就绪、非自家农场、无匹配地块和执行中状态正确禁用并显示原因。
5. 桌面端菜单的 ARIA、关闭行为，以及 LAN 手机端的 42px 命令行和底部抽屉 CSS 契约。

验证执行聚焦土地视图测试、完整前端测试和 `frontend` 生产构建；最后在桌面宽度、`760px` 和 `360px` 的 LAN 布局下检查菜单位置、抽屉可达性及无横向溢出。

## 非目标

- 不改变自动农场的种植策略、任务调度或运行时协议。
- 不改变现有催熟、施肥、单块施肥和单块铲除的筛选逻辑。
- 不增加好友农场的批量操作。
- 不修改好友列表菜单、LAN 授权或后端 API 形状。
